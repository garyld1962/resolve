# Resolve — Strategic Decision Log

AI-native decision log companion to Linear. Records, chains, and traces strategic decisions across development projects.

## Key Features

- **Integrity chain**: SHA-256 hash chain with Merkle accumulator for tamper-evident decisions
- **Cross-project tracing**: Impact radius matching across Baker Street and BuildFlow
- **AI-native API**: REST + MCP server for Claude Code / Baker Street agents
- **Semantic search**: Voyage embeddings for decision similarity and conflict detection
